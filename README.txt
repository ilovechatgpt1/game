# مهمة النجاة — نسخة قابلة للتثبيت

## النشر على GitHub Pages
1. أنشئ مجلداً اسمه `game` داخل مستودعك.
2. ارفع **كل الملفات الأربعة** داخل المجلد: `index.html` و`manifest.webmanifest` و`sw.js` و`icon.svg`.
3. انتظر نجاح GitHub Pages.
4. افتح: `https://ilovechatgpt1.github.io/-/game/` من Chrome على Android.

## التثبيت على Android
- افتح رابط اللعبة في Chrome.
- اضغط قائمة ⋮.
- اختر **Install app / تثبيت التطبيق** أو **Add to Home screen / إضافة إلى الشاشة الرئيسية**.
- وافق على التثبيت. ستظهر اللعبة بأيقونتها وتفتح بواجهة مستقلة.

ملاحظة: التثبيت يحتاج الموقع منشوراً عبر HTTPS. بعد أول فتح ناجح، ملفات اللعبة الأساسية تُخزّن لتعمل دون اتصال. هذه نسخة PWA وليست ملف APK.
